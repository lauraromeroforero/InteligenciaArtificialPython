ACTIVIDAD 3 — APRENDIZAJE SUPERVISADO
Para ejecutar mi proyecto desde la carpeta principal, utilizo Python 3.10 o posterior:

python -m venv .venv
Linux/macOS: source .venv/bin/activate
Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r actividad3/requirements.txt
python actividad3/modelo_transporte.py
python -m unittest discover -s actividad3/tests -v

En Windows puedo usar py en lugar de python si corresponde.
El CSV ya está incluido. Para regenerarlo de manera determinista, ejecuto:
python actividad3/generar_datos.py

Utilicé un árbol de regresión para predecir minutos.
El dataset contiene 600 registros SINTÉTICOS, no mediciones reales.
Separé 480 registros para entrenamiento y 120 para prueba, con semilla 42.
Elegí los hiperparámetros mediante validación cruzada de cinco particiones
solo sobre entrenamiento. No utilicé la prueba para elegir el árbol.
Comparé mi modelo con uno que predice la media del entrenamiento.
Resultados: resultados/metricas.json, predicciones_prueba.csv y reglas_arbol.txt.
MAE esperado aproximadamente 4.34 minutos frente a 12.94 del baseline.
Estas métricas solo evalúan el proceso simulado y no permiten predecir viajes reales.
